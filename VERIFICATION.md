## Method

The same method as the demo video: a headless browser shows each step and a frame is captured. Commands that write (submit, review, merge, the issue form, gold sync, handle change, evals) run in a throwaway clone with no remote, so nothing here can push and the real repository is compared before and after. A command passes only when its exit code is the expected one and the expected text is on the captured frame. Browser steps pass only when the entries shown equal what the entry files say should be shown.
